Small tools for the hardware you own.

7 open source

  • Keepsake Atelier

    Rust · Tauri 2 · MIT

    Rip, author, verify and burn Blu-ray and DVD discs, with the tooling in the app instead of behind a licence server.

    • Native AACS key recovery, UDF 2.50 images and 1:1 clones
    • Authored BD-J menus, playlists and chapter marks
    • Verify before you burn, then burn at the right speed
    • MCP server, so an agent can drive a rip or a build
    Website Source

  • GODsend 360

    Go · MIT

    An Xbox 360 game manager for Aurora consoles: browse a library, convert it, and push it over FTP without a laptop relay.

    • Minerva (BitTorrent) and Internet Archive sources, searched in app
    • Pure-Go ISO to GOD conversion, no Windows-only tooling
    • DLC, title updates, save backup and restore over FTP
    • RXEA asset editor for Aurora art and text
    Website Source

  • GODsend PSP

    Rust · Tauri 2 · MIT

    Plug a PSP in over USB and manage the whole memory stick from one window: games, homebrew, media, saves, mods.

    • Library built from PARAM.SFO and PBP headers, with ICON0 cover art
    • Bundled homebrew catalogue with per-archive layout detection
    • Music and video converted to PSP formats with ffmpeg
    • ISO and CSO images, saves and mods, one short video per tab
    Website Source

  • GODsend PS3

    Rust · Tauri 2 · MIT

    A desktop workshop for a CFW or HEN PlayStation 3: read the library over FTP, drive the console, install games and homebrew back onto it.

    • Library from PARAM.SFO over FTP, mounted or launched through webMAN
    • On-screen DualShock pad, keyboard mapping and text macros
    • Game folder, ISO and FAT32 split conversions, plus Redump decrypt
    • Loopback MCP server, so an agent drives the same paths as the UI
    Website Source

  • Browser Bridge

    TypeScript · MIT

    Let a terminal agent drive the Chrome you actually use, with your profile and your logins, from a command line.

    • Runs as an extension inside your profile, where the DevTools port is refused
    • Only tabs the agent opened or adopted, in their own tab group
    • Numbered snapshots, click, type, scroll, wait, eval, screenshot
    • The daemon binds 127.0.0.1 only; nothing is exposed to the network
    Website Source

  • PS3 Quick Disc Decryptor

    Swift 6 · GPL-3.0 · macOS

    A native macOS app that decrypts Redump PS3 disc images so RPCS3 can load them.

    • No dependencies: CommonCrypto already ships with macOS
    • About 1 GiB/s, so a 9 GB disc takes roughly 8 seconds
    • Takes a folder of .dkey files or one combined key file
    • Batch queue with per-file progress, and atomic .part output
    Website Source

  • Stripchat Recorder

    Rust · Tauri 2 · MIT · 18+

    A desktop recorder for Stripchat live rooms, pulled straight from the CDN at source quality.

    • Reads the site's HLS playlist directly, no browser and no screen capture
    • Decodes the MOUFLON v2 segment obfuscation in-app
    • Append-only recording: a dropped connection cannot corrupt the file
    • Splits into parts, then remuxes or compresses with CRF presets
    Website Source
