Small tools, no accounts, no subscriptions.

GhostShell is two open-source desktop apps for jobs the big software puts behind a licence: reading and authoring the discs you already own, and getting games onto an Xbox 360 without a laptop relay.

  • Keepsake Atelier

    Rip, author, verify and burn Blu-ray and DVD discs with native tooling. AACS key recovery, UDF 2.50 images, authored BD-J menus, 1:1 clones, and an MCP server for agents.

    macOS · Linux · Windows

  • GODsend 360

    An Xbox 360 game manager for Aurora consoles: browse Minerva Archive and Internet Archive, convert ISO to GOD on the fly, push DLC, title updates and save backups over FTP.

    Windows · macOS · Linux
